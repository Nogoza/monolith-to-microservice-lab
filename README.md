# About

An e-commerce application built with Django + PostgreSQL.
It includes product catalog, shopping cart, order, payment, and reporting workflows.

The application was designed to run as a single instance on a single server.

The application code was generated using AI agents. It is fully functional;
orders can be placed, payments can be processed, and data consistency is maintained.

## Running the Application

Docker and Docker Compose are required.
See the `README.md` file for installation steps and instructions for loading sample data.

## Objective

The application code will not be modified. The work is focused on the infrastructure side:
keeping the application running, monitoring it, backing it up, updating it, and scaling it.

The infrastructure should be designed according to the requirements defined in
`tasks.md`.

The choice of tools is flexible; there is no single correct solution.
